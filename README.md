# Tripleten web_project_homeland

Homeland
Proyecto web estático desarrollado para reproducir un diseño proporcionado en Figma, aplicando principios de maquetación moderna y diseño responsivo.

Tecnologías utilizadas
-HTML5
Estructura semántica del contenido.
-CSS3
Flexbox para layout
-Media Queries para diseño responsivo
-Metodología BEM para la organización de clases
-Enfoque monitor-first

Organización del proyecto
Los estilos están divididos en archivos CSS independientes para mejorar el orden y mantenimiento del código:
-page.css
-header.css
-logo.css
-content.css
-information.css
-footer.css

Diseño responsivo
El sitio se adapta a:
-Monitores
-Tablets
-Celulares
Mediante media queries que ajustan tipografía, tamaños y espaciados.
